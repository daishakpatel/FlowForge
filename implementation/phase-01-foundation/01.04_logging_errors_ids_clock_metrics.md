## 3. Objective

Implement the small shared libraries every later task depends on: structured logging with context fields and redaction, the application error type mapped to HTTP/gRPC, prefixed ULID identifiers, an injectable clock, and a Prometheus registry/HTTP helper (`/metrics`, `/healthz`).

## 4. Detailed Implementation Requirements

- `internal/logging`: `slog` JSON handler factory (`New(cfg) *slog.Logger`), context helpers `WithFields(ctx, …)` / `FromContext(ctx)`, canonical field names from `00E §11` (`request_id, run_id, task_id, attempt_id, worker_id, trace_id, span_id`), a redacting handler that masks values for keys matching `(?i)(password|secret|token|api[_-]?key|authorization|dsn)` and secret-shaped strings (`ff_[A-Za-z0-9]+_[A-Za-z0-9]{16,}`, bearer tokens, `postgres://user:pass@`).
- `internal/apperrors`: `type Error struct{Code Code; Message string; Details []Detail; Cause error; RetryAfter time.Duration}`, `Code` constants exactly as `00E §4`, constructors (`NotFound`, `Conflict`, `InvalidState`, `StaleAttempt`, …), `Is/As` support, `HTTPStatus(code)`, `GRPCCode(code)`, `FromError(err)` (maps unknown → INTERNAL with sanitized message).
- `internal/ids`: `New(prefix) string` generating `prefix_<ULID>` using `oklog/ulid/v2` with a monotonic entropy source; `Generator` interface (real + deterministic fake for tests); `Parse/Validate(prefix, s)`; constants for prefixes (`wf, run, task, att, evt, inv, apr, req, trg`).
- `internal/clock`: `Clock` interface (`Now() time.Time`, `After`, `NewTimer`, `NewTicker`, `Sleep(ctx,d)`), `Real`, and `Fake` (manually advanced; deterministic timer firing order; safe for concurrent use). Tighten the `forbidigo` rule from 01.01: `time.Now`/`time.Sleep`/`time.After`/`time.NewTimer`/`time.NewTicker` forbidden outside `internal/clock` and `cmd/**`.
- `internal/obs`: `Registry` wrapper over `prometheus.Registry` with Go/process collectors, `NewServer(addr, registry, readiness ...ReadinessCheck) *http.Server` exposing `/metrics`, `/healthz`, `/readyz`; helper constructors that enforce the naming convention (reject labels outside the allowed low-cardinality list).

## 5. Technical Design

```go
// apperrors (sketch)
type Code string // INVALID_ARGUMENT, INVALID_WORKFLOW, UNAUTHENTICATED, PERMISSION_DENIED, NOT_FOUND, CONFLICT,
                 // INVALID_STATE, STALE_ATTEMPT, PAYLOAD_TOO_LARGE, RATE_LIMITED, UNAVAILABLE, INTERNAL, NOT_LEADER, NO_QUORUM
func (e *Error) Error() string; func (e *Error) Unwrap() error
func HTTPStatus(c Code) int; func GRPCCode(c Code) codes.Code
```
```go
// clock (sketch)
type Clock interface { Now() time.Time; Sleep(ctx context.Context, d time.Duration) error
  NewTimer(d time.Duration) Timer; NewTicker(d time.Duration) Ticker; After(d time.Duration) <-chan time.Time }
```
Redaction is applied at the logging handler **and** exposed as `logging.Redact(string) string` for reuse by audit/task-log shipping (03.01) and AI evidence capture (06.04).

**Design notes / edge cases:**

- `Fake` clock timers must fire in deadline order and, for equal deadlines, creation order; `Advance(d)` must run due timers synchronously before returning (tests rely on determinism).
- ULID monotonicity must hold under concurrent calls (mutex-protected entropy).

## 8. Testing Requirements

- apperrors: every `00E §4` code maps to the documented HTTP and gRPC codes; `errors.As` works through wrapping; unknown errors → INTERNAL with sanitized message.
- ids: prefix validation rejects wrong prefix; 1000 IDs generated concurrently are unique and, per goroutine, increasing.
- clock.Fake: `Advance` fires timers in order; stopped timers do not fire; ticker delivers N ticks for N×period; no goroutine leaks (goleak).
- logging: password/token/api-key/DSN-with-password never appear in output; pattern redaction masks `ff_abc_<secret>`; context fields included automatically.
- obs: `/healthz` 200; readiness check failing → `/readyz` 503; label allow-list violation panics at registration (documented) or returns error.

General: `make lint` and `make test` must pass; run packages you touched with `-race`; record exact commands and results in the completion report.
