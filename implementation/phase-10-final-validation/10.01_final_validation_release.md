## 3. Objective

Close the project: prove every requirement in the master spec is implemented and tested, run the full regression across all suites, verify coverage gates and migrations, and produce the release notes and final completion report.

## 4. Detailed Implementation Requirements

- Traceability: `scripts/ci/traceability.go` parses the master spec requirement IDs and a `docs/traceability.md` map (requirement → implementing task → tests/files); fails if any requirement lacks implementation evidence (test name or file path that exists). Generate and commit `docs/traceability.md`.
- Full regression: `make verify-all` = lint (Go, Python, TS, proto, OpenAPI, SQL), unit with `-race`, integration (testcontainers), contract/drift checks, migrations (up-from-empty and up-from-previous), coverage gates (≥ 70 % on `internal/{dag,workflow,scheduler,raftkv,stream}`), web tests, AI eval gate, observability check, fault suites (workflow, raft, streaming, chaos subset), `make demo`. Record durations.
- Migration tests: apply all migrations from empty, and from a snapshot of the previous release schema (tag fixtures per phase), ensure idempotency and no destructive change (NFR-DEV-03).
- Release assets: `CHANGELOG.md`, version tag `v1.0.0` plan, release checklist (`docs/release-checklist.md`), `docs/final-completion-report.md` (what was built, requirement coverage table, test/benchmark/fault report links, known limitations, deviations from the blueprint with justification, optional items not done).
- Audit leftovers: grep for TODO/FIXME/`panic("not implemented")`, unreferenced feature flags, stale docs; update `00B` progress checklist final state (if repo includes blueprint) and ADR statuses (Accepted/Superseded).
