## 3. Objective

Create the React + Vite + TypeScript operations dashboard foundation: API-key login, role-aware navigation, typed API client generated from OpenAPI, workflow definition and run pages, and a resilient SSE live-update layer with `Last-Event-ID` resume.

## 4. Detailed Implementation Requirements

- `web/` project: React 18, Vite, TypeScript strict, React Router, TanStack Query, Zustand (auth/session), Tailwind (or CSS modules), ESLint/Prettier, Vitest + Testing Library, Playwright. `make web-lint web-test web-build web-dev`; CI job added.
- Typed client generated from `api/openapi/flowforge.v1.yaml` (`openapi-typescript` + thin fetch wrapper); generation drift check in CI. Error envelope → typed `ApiError` with `code`, `request_id` shown in error UI.
- Auth: API-key login form → validate via `GET /api/v1/me`; key stored in memory + `sessionStorage` (documented trade-off; never localStorage); logout clears; 401 → login redirect; role from `/me` drives nav and hides unauthorized actions (server remains authority).
- Layout/nav: Runs, Definitions, Workers & Cluster (placeholder), Market Data (placeholder), AI (placeholder), Settings(key info). Global states: loading skeletons, empty states, error boundaries with retry.
- Pages: Definitions list/detail (YAML view, DAG preview placeholder), **Start run** dialog (inputs JSON editor with validation, idempotency key auto-generated), Runs list (filters: status, definition, time; pagination), Run detail shell (summary + task table; DAG added in 07.02).
- SSE layer `useEventStream`: connects to `/api/v1/events/stream` with auth (use `fetch`-based SSE or event-source polyfill supporting headers), tracks last event id, reconnect with exponential backoff + jitter, resumes via `Last-Event-ID`, de-dupes by `event_id`, invalidates relevant TanStack queries; connection status indicator; falls back to polling at 5 s after 3 failed reconnects.

## 5. Technical Design

State flow: server state in TanStack Query; SSE events patch/invalidate query caches (never a parallel source of truth). On reconnect after a gap larger than the retention of the stream (server returns `RESET`), the client refetches everything.

**Design notes / edge cases:**

- No secrets in URLs.
- Accessibility basics: semantic HTML, keyboard nav, focus management in dialogs, AA contrast.
