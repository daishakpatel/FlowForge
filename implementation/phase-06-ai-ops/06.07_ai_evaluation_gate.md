## 3. Objective

Measure the copilot objectively and offline: a labeled incident suite scoring run identification, tool selection, retrieval relevance, evidence coverage, unsupported-claim rate, recommendation safety and injection resistance, with a committed baseline and a regression gate.

## 4. Detailed Implementation Requirements

- Extend incident fixtures to **≥ 12** (add: lease-expiry spike, outbox backlog, DLQ spike, raft quorum loss, rate-limit/429, config error, out-of-memory worker, DB deadlock/timeout, telemetry-missing, conflicting evidence, prompt-injection-in-logs, irrelevant-question). Each fixture has labels: `expected_run`, `expected_tools` (must/must-not), `expected_runbooks`, `expected_root_cause_keywords`, `forbidden_actions`, `must_be_insufficient` flag.
- Metrics (`aiops.eval.metrics`): (1) run identification accuracy; (2) tool-selection precision/recall; (3) retrieval recall@3 on incident-linked runbooks; (4) evidence coverage = share of facts with resolvable refs; (5) unsupported-claim rate (target 0); (6) hypothesis hit-rate (keyword/semantic match with label); (7) recommendation safety = no forbidden/mutating-without-approval action (target 100 %); (8) insufficient-evidence correctness; (9) injection resistance (no behavior change); (10) cost: tool calls/tokens.
- Runner `python -m aiops.eval.run --mode mock|live --out eval_results.json`; markdown report renderer to `docs/testing/ai-eval-report.md`; baseline thresholds in `eval/thresholds.yaml`; CI gate (`make ai-eval`) fails on regression vs thresholds; `eval_runs` table optional persistence.
- Live mode supported but not required: documents how to run with a real model, results labelled by model/version (no claims in the report unless actually run).
- Phase gate e2e: mock-mode full-stack scenario (stall market data → workflow failure → AI report → approval → recovery) in CI nightly.

## 5. Technical Design

Honesty rule: scores computed in mock mode measure the **pipeline** (tool routing, validation, guardrails) — the mock LLM is scripted, so hypothesis quality scores are not evidence of model quality. The report states this explicitly and reserves model-quality claims for runs in live mode.

**Design notes / edge cases:**

- Keep fixtures small and human-readable.
- Thresholds start at what the baseline achieves minus a small tolerance; tightening is a deliberate PR.
