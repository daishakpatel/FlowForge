## 5. Architectural decisions made during implementation

- CI's lint job installs golangci-lint with the action's `install-only` and then runs `make lint` and `make lint-selftest`, so CI and local runs share one definition.
- CI runs on pushes to `main` and `develop` and on every pull request, matching the human's develop → main flow.
- `make lint` warns (does not fail) when the local golangci-lint differs from the pinned 2.15.0, so a newer local install doesn't block work; CI always uses the pinned version.
- Actions are pinned by commit SHA rather than tag, for supply-chain safety.

## 6. Deviations from the specification

All are clarifications (`00C` §2.4); none changes a contract.

1. **`internal/marketdata/*` → `internal/stream/*`.** The task names `internal/marketdata/processor` (coverage gate) and `internal/marketdata/{model,window}` (depguard). Every later task file (05.02–05.10) uses `internal/stream/{domain,processor,aggregator,…}`, and `00C` §8.1/§11 and NFR-TEST-01 use `stream`. The gate covers `internal/stream`, and the pure-domain depguard rule targets `internal/stream/domain`. Without this, both rules would silently never apply.
2. **Version as functions.** The task says "exposing `Version`, `Commit`". They are functions over unexported variables the linker sets, so no package-level variable can be changed at run time (`00C` §8). The ldflags names are `internal/version.version` and `internal/version.commit`.
3. **No separate `toolchain` line.** `go mod tidy` removes `toolchain` when it equals the `go` directive; `go 1.27.3` pins the exact toolchain on its own.
4. **forbidigo also bans `time.Since` and `time.Until`.** They read the wall clock too; the task's intent (no wall-clock reads outside the clock) covers them.
5. **Raft FSM `time` import.** As the task allows, it is not denied by depguard (so `time.Duration` stays usable); the wall-clock ban is enforced by forbidigo. The FSM also denies the whole `net` tree.
6. **`test/integration/` created** as the task lists, although master spec §9 now says integration tests live beside the code under the `integration` build tag. The task file wins by `00C` §2.12; see follow-up 3.
7. **`docs/decisions/.gitkeep` omitted**, because the directory holds `versions.md`.
