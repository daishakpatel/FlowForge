## 1. What was implemented

- **`internal/logging`** (`logger.go`, `context.go`, `redact.go`):
  - `New(Config) *slog.Logger` builds a JSON (or text) handler with the `00E` §11 field names; the timestamp key is renamed to `ts`, and `service` and `version` are added.
  - `Key*` constants for the canonical fields, and `Err(err)` for the `err` field.
  - `WithFields(ctx, …)`, `NewContext(ctx, l)`, `FromContext(ctx)`. A context handler adds context fields to every `…Context` call without duplicating keys already on the record or bound with `With`.
  - Redaction runs in the handler's `ReplaceAttr` hook, so it covers bound attributes, nested groups, resolved `LogValuer` values and the message. Values under sensitive keys or group names (`password|passwd|secret|token|api[_-]?key|authorization|dsn`) become `***`. `Redact(string)` masks `ff_<id>_<secret>` keys, bearer tokens, `postgres://user:pass@` passwords, and `key=value` / `key: value` / JSON forms. Error text, and structs or maps whose text contains a secret, are masked too.
- **`internal/apperrors`** (`errors.go`, `codes.go`, `http.go`, `grpc.go`):
  - `Code` with the 14 `00E` §4 constants (`CodeInvalidArgument` … `CodeNoQuorum`) and `Codes()`.
  - `Error{Code, Message, Details, Cause, RetryAfter}` with `Error`, `Unwrap`, and `Is` (matches by code).
  - Constructors for every code, plus `New` and `Wrap`.
  - `FromError` (unknown errors become `INTERNAL` with the message "internal error"; the cause is kept), `CodeOf`, `Retryable`, `Code.Retryable`, `HTTPStatus`, `GRPCCode`.
- **`internal/ids`** (`ids.go`, `fake.go`):
  - Prefix constants `wf run task att evt inv apr req trg`, and the `Generator` interface.
  - `ULIDGenerator` / `NewGenerator(clock, entropy)`. It's monotonic across goroutines: the time read and the monotonic entropy are under one mutex, the timestamp never goes backwards, and entropy overflow borrows the next millisecond.
  - Package `New(prefix)`, `Parse`, `Validate`, `ErrInvalid`, and a deterministic `Fake`.
- **`internal/clock`** (`clock.go`, `real.go`, `fake.go`):
  - `Clock` (`Now`, `Sleep(ctx, d)`, `NewTimer`, `NewTicker`, `After`), plus the `Timer` and `Ticker` interfaces.
  - `Real`, and `Fake` (`NewFake`, `Advance`, `Set`, `Waiters`, `BlockUntilWaiters`). `Fake` fires due timers synchronously in deadline order, then creation order, with `Now` set to each deadline as it fires. `Stop` and `Reset` drop stale values, unread ticks are dropped, it starts no goroutines, and it's mutex-guarded.
- **`internal/obs`** (`registry.go`, `server.go`, `labels.go`):
  - `Registry` / `NewRegistry()` registers the Go and process collectors. `Counter`, `Gauge` and `Histogram` reject bad names (`flowforge_…`; `_total` only, and always, on counters) and labels outside `AllowedLabels()`, with `ErrInvalidMetric`.
  - `NewServer(addr, reg, ...ReadinessCheck) *http.Server` serves `/metrics`, `/healthz` and `/readyz` (503 with per-check `ok`/`fail` and no error text; 5 s timeout), with read, write and idle timeouts set.
- **Lint:** forbidigo now bans `time.Now|Since|Until|Sleep|After|AfterFunc|Tick|NewTimer|NewTicker` outside `cmd/**` and `internal/clock`. `internal/clock` is exempt only from the time rule, so the 01.03 env ban now applies there too. `make lint-selftest` checks `time.Now`, `time.NewTimer` and `os.Getenv`.
- **Violations fixed:** `internal/testutil/eventually.go` used `time.NewTimer` and `time.NewTicker`; it now uses `clock.Real`, with unchanged behaviour.
- **Docs:** `docs/architecture/cross-cutting.md`, linked from `README.md`.

## 5. Architectural decisions made during implementation

- **Redaction in `ReplaceAttr`, not a wrapping handler.** The built-in slog handlers call it for every attribute (bound ones too, inside groups, after `LogValue`) and for the message, so one function covers every path a wrapper would have had to walk itself.
- **Context fields are added by the handler and also bound by `FromContext`**, with key-based de-duplication. Request IDs then appear whether code logs through an injected logger with `InfoContext(ctx, …)` or through `FromContext(ctx)`.
- **`logging.Config` is its own type**, not `config.Common`, so the platform packages don't depend on each other; `main` maps `Common.LogLevel`/`LogFormat` into it.
- **`clock.Fake` fires synchronously and uses one-value channels**, matching `time.Timer` semantics (stale values dropped on `Stop`/`Reset`, unread ticks dropped), with no goroutines, so goleak stays trivially clean.
- **`obs.Registry` hides the Prometheus registry**, so every metric goes through the name and label checks; `NewServer` is the only reader.
- **`/readyz` reports `ok`/`fail` per check without error text** because it's unauthenticated (`00C` §10.1).

## 6. Deviations from the specification

All are clarifications (`00C` §2.4):

1. **`ids.New(prefix)` uses one package-level generator.** The task requires a package function that is monotonic under concurrency, which needs shared, mutex-guarded state; `00C` §8 otherwise forbids package-level mutable variables. The exception is confined to `defaultGenerator` and documented. Code with an injected `Generator` doesn't use it. (01.02's `testutil` has the same kind of exception.)
2. **`CONFLICT` → gRPC `AlreadyExists`.** `00E` §4 lists "ALREADY_EXISTS / ABORTED", but one mapping function returns one code. A handler can choose `Aborted` for version conflicts explicitly.
3. **`NOT_LEADER` and `NO_QUORUM` → HTTP 503.** `00E` §4 gives "—", since they're internal codes; if one reaches HTTP, 503 tells the client to retry.
4. **Label allow-list.** `00E` §11 names eight labels, but its own metrics use eleven more (`route method code peer reason stage kind tool disposition result symbol`). `AllowedLabels()` is the union, and the `00E` §11 sentence now lists them. Nothing renamed or removed.
5. **Panics.** `Fake.NewTicker` and ticker `Reset` panic on a non-positive period, as `time.NewTicker` does. `ULIDGenerator.New` panics if the entropy source fails, which `crypto/rand.Reader` never does. `NewRegistry` uses `MustRegister` for two built-in collectors on a fresh registry, which can't conflict. All are programmer errors (`00C` §10.1).
6. **The redaction key pattern also includes `passwd`**, alongside the task's list, and a key=value text pattern, so secrets inside formatted text and `%+v` output are caught too.
7. **`New(cfg)` falls back to `info` and JSON** for an unknown level or format instead of returning an error, keeping the task's signature. `internal/config` already validates both values.
8. **Files outside §7:** `internal/testutil/eventually.go` (lint fix the task asks for), the lint self-test script and fixture, `go.mod`/`go.sum`, `README.md`, `versions.md`, `00E`.

## 7. Known limitations / follow-ups

1. **Indirect modules moved up** because gRPC v1.85.0 and Prometheus v1.25.0 require newer minimums: `protobuf` v1.36.12, `otel` v1.45.0, `go-logr/logr` v1.4.4, `klauspost/compress` v1.20.1. These came from minimum version selection, not deliberate upgrades; recorded in `versions.md`.
2. **Context fields logged under an open group** (`WithGroup`) land inside that group.
3. **Redaction is pattern-based**: a secret in an unrecognised shape under an innocuous key isn't caught. Credentials still belong in `config.Secret`.
4. **`trace_id`/`span_id` are constants only**; 08.01 (OpenTelemetry) should add them via `logging.WithFields` or a handler that reads the span from the context.
5. **CI is still unverified** (GitHub billing lock).
